# Engineering Document Intelligence Assistant
An AI-powered assistant for answering questions about engineering documents such as datasheets, textbooks, technical notes, and application notes

## Project Goal
This system will use retrieval-augmented generation (RAG) to retrieve relevant information from technical documents and provide grounded answers with citations.

Additionally, it will also use deterministic tools for engineering calculations and unit conversions. 

## Planned Features
- PDF document ingestion
- Text extraction
- Semantic search
- Retrieval-augmented generation
- Page-level citations
- Unit conversion
- Engineering calculations
- Multiple-document search
- Retrieval and answer evaluation
- Interactive web interface

## Planned Technology
- Python
- PyMuPDF
- Sentence Transformers
- FAISS
- LLM
- Pint
- Streamlit

## Engineering Questions the System Should Answer
1. What is the maximum operating voltage for this component?
2. What is the typical supply current?
3. What are the recommended operating conditions?
4. What are the absolute maximum ratings?
5. What is the operating temperature range?
